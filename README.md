# Airhead

An offline-first PWA for capture, planning and organisation, for iPhone, iPad and desktop Chrome.

- What and why: [docs/DESIGN.md](docs/DESIGN.md)
- Task list: [docs/PLAN.md](docs/PLAN.md)
- Decisions and library versions: [docs/DECISIONS.md](docs/DECISIONS.md)
- Waiting on a human: [docs/BLOCKERS.md](docs/BLOCKERS.md)

## Commands

```bash
npm install
npm run dev        # http://localhost:5173
npm run lint       # ESLint + Prettier check
npm run typecheck
npm test           # Vitest
npm run test:e2e   # Playwright
```
